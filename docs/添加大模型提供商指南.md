## 概述

OpenPlayground 支持多种大语言模型提供商（如 OpenAI、Cohere、Anthropic 等）。要添加新的提供商，需要在多个层面进行修改：

1. **数据层**：定义提供商和模型的配置结构
2. **推理层**：实现与提供商 API 的交互逻辑
3. **应用层**：注册路由和请求处理
4. **存储层**：加载和管理配置

---

## 架构理解

项目的核心文件结构如下：

```
server/
├── lib/
│   ├── entities.py          # 数据实体定义（Provider, Model 等）
│   ├── inference/
│   │   └── __init__.py      # 推理管理器（核心推理逻辑）
│   └── storage.py           # 配置存储和加载
├── app.py                   # Flask 应用和路由
└── models.json              # 模型配置文件
```

## 实施步骤

### 步骤 1: 修改数据实体

**文件**: `server/lib/entities.py`

如果新提供商需要额外的配置字段（如自定义 API URL），需要在 `Provider` 类中添加相应属性。

#### 示例：添加 `api_url` 字段

```python
class Provider:
    def __init__(
        self, name: str, models: List[Model], remote_inference: bool = False,
        default_capabilities: List[str] = None, default_parameters: dict = None,
        api_key: str = None, requires_api_key: bool = False,
        search_url: str = None, api_url: str = None  # 新增字段
    ):
        self.event_emitter = EventEmitter()
        self.name = name
        self.models = models
        self.remote_inference = remote_inference
        self.default_capabilities = default_capabilities or []
        self.default_parameters = default_parameters
        self.api_key = api_key
        self.requires_api_key = requires_api_key
        self.search_url = search_url
        self.api_url = api_url  # 保存自定义 API URL
```

**说明**：
- `api_url` 用于指定非标准的 API 端点（如本地部署的 Ollama）
- 如果提供商使用标准端点且不需要额外配置，可跳过此步骤

### 步骤 2: 配置模型信息

**文件**: `server/models.json`

在 `models.json` 中添加新提供商的配置。每个提供商需要定义：

- **提供商级别配置**：
  - `requiresAPIKey`: 是否需要 API 密钥
  - `remoteInference`: 是否远程推理
  - `apiURL`: 自定义 API URL（可选）
  - `defaultParameters`: 默认参数配置（可选）

- **模型级别配置**：
  - `enabled`: 是否启用
  - `status`: 状态（如 "ready"）
  - `capabilities`: 支持的功能（如 "logprobs"）
  - `parameters`: 可调参数及其范围

#### 3.2 更新 ProviderDetails

```python
class ProviderDetails:
    '''
    Args:
```

#### 3.3 实现推理方法

需要实现两个方法：
1. **私有方法** (`__xxx_text_generation__`): 包含实际推理逻辑
2. **公共方法** (`xxx_text_generation`): 通过错误处理器包装

##### 完整示例：Ollama 文本生成

```python
def __ollama_text_generation__(self, provider_details: ProviderDetails, inference_request: InferenceRequest):
    """
    Ollama文本生成函数（使用官方Python库）
    支持流式响应
    """
    # 1. 配置客户端
    api_url = getattr(provider_details, 'api_url', 'http://localhost:11434')
    client = ollama.Client(host=api_url)
    
    # 2. 构建生成参数
    options = {
        "temperature": inference_request.model_parameters.get('temperature', 0.7),
        "top_p": inference_request.model_parameters.get('topP', 0.9),
        "top_k": inference_request.model_parameters.get('topK', 40),
        "num_predict": inference_request.model_parameters.get('maximumLength', 512),
        "repeat_penalty": inference_request.model_parameters.get('repetitionPenalty', 1.1),
    }
    
    # 添加停止序列
    stop_sequences = inference_request.model_parameters.get('stopSequences', [])
    if stop_sequences:
        options["stop"] = stop_sequences
    
    cancelled = False
    logger.info(f"Starting Ollama inference for {inference_request.uuid} - {inference_request.model_name}")
    
    try:
        # 3. 调用 API（流式）
        response = client.generate(
            model=inference_request.model_name,
            prompt=inference_request.prompt,
            options=options,
            stream=True  # 启用流式响应
        )
        
        # 4. 处理流式响应
        for chunk in response:
            if cancelled:
                break
            
            # 提取生成的 token
            generated_token = chunk.get('response', '')
            
            if generated_token:
                # 构建推理结果
                infer_response = InferenceResult(
                    uuid=inference_request.uuid,
                    model_name=inference_request.model_name,
                    model_tag=inference_request.model_tag,
                    model_provider=inference_request.model_provider,
                    token=generated_token,
                    probability=None,  # Ollama 默认不返回 token 概率
                    top_n_distribution=None
                )
                
                # 发送推理结果到前端
                if not self.announcer.announce(infer_response, event="infer"):
                    cancelled = True
                    logger.info(f"Cancelled inference for {inference_request.uuid}")
        
        logger.info(f"Ollama生成完成: {inference_request.uuid}")
        
    except ollama.ResponseError as e:
        raise Exception(f"Ollama API错误: {e.error} (状态码: {e.status_code})")
    except Exception as e:
        raise Exception(f"Ollama文本生成失败: {str(e)}")


def ollama_text_generation(self, provider_details: ProviderDetails, inference_request: InferenceRequest):
    """
    Ollama文本生成的公共方法
    通过错误处理器包装
    """
    self.__error_handler__(self.__ollama_text_generation__, provider_details, inference_request)
```

**关键要点**：

1. **流式处理**：
   - 设置 `stream=True` 启用流式响应
   - 逐块处理响应，实时推送给前端
   - 支持用户取消操作（检查 `cancelled` 标志）

2. **参数映射**：
   - 将前端的参数名称映射到提供商 API 的参数名称
   - 提供合理的默认值

3. **错误处理**：
   - 捕获特定异常（如 `ollama.ResponseError`）
   - 提供清晰的错误信息

4. **结果构建**：
   - 使用 `InferenceResult` 封装每个 token
   - 通过 `announcer.announce()` 推送到前端

## 流式请求最小化代码示例

以下是一个独立的、最小化的流式请求示例，展示了如何为新提供商实现流式推理。这个示例可以直接用于测试和理解核心逻辑。

### 示例 1: 使用官方 Python 库（推荐）

```python
import ollama
from typing import Generator

def stream_chat_with_ollama(model: str, prompt: str, api_url: str = "http://localhost:11434"):
    """
    使用 Ollama 官方库进行流式聊天
    
    参数:
        model: 模型名称（如 "llama3", "gemma4:e4b"）
        prompt: 用户输入的提示词
        api_url: Ollama 服务地址
    
    生成:
        逐个返回生成的 token
    """
    # 1. 初始化客户端
    client = ollama.Client(host=api_url)
    
    # 2. 配置参数
    options = {
        "temperature": 0.7,
        "top_p": 0.9,
        "top_k": 40,
        "num_predict": 512,
    }
    
    # 3. 发起流式请求
    response = client.generate(
        model=model,
        prompt=prompt,
        options=options,
        stream=True  # 关键：启用流式
    )
    
    # 4. 处理流式响应
    for chunk in response:
        token = chunk.get('response', '')
        if token:
            yield token  # 逐个返回 token


# 使用示例
if __name__ == "__main__":
    for token in stream_chat_with_ollama("gemma4:e4b", "你好，请介绍一下自己"):
        print(token, end="", flush=True)
```

### 示例 2: 使用 HTTP 请求（通用方案）

如果提供商没有官方 Python 库，可以使用 `requests` 或 `aiohttp` 直接调用 API。

```python
import requests
import json
from typing import Generator

def stream_chat_with_http(api_url: str, model: str, prompt: str, api_key: str = None):
    """
    使用 HTTP POST 请求进行流式聊天（通用方案）
    
    参数:
        api_url: API 端点地址
        model: 模型名称
        prompt: 用户提示词
        api_key: API 密钥（如果需要）
    
    生成:
        逐个返回生成的 token
    """
    headers = {
        "Content-Type": "application/json",
    }
    
    # 如果需要 API 密钥
    if api_key:
        headers["Authorization"] = f"Bearer {api_key}"
    
    payload = {
        "model": model,
        "prompt": prompt,
        "stream": True,  # 启用流式
        "options": {
            "temperature": 0.7,
            "top_p": 0.9,
        }
    }
    
    # 发起流式请求
    response = requests.post(
        api_url,
        headers=headers,
        json=payload,
        stream=True  # 关键：启用 requests 的流式模式
    )
    
    # 处理流式响应
    for line in response.iter_lines():
        if line:
            try:
                data = json.loads(line.decode('utf-8'))
                token = data.get('response', '')
                if token:
                    yield token
            except json.JSONDecodeError:
                continue


# 使用示例
if __name__ == "__main__":
    api_url = "http://localhost:11434/api/generate"
    for token in stream_chat_with_http(api_url, "llama3", "什么是人工智能？"):
        print(token, end="", flush=True)
```

### 示例 3: 异步流式请求（高性能场景）

```python
import aiohttp
import asyncio
from typing import AsyncGenerator

async def stream_chat_async(api_url: str, model: str, prompt: str) -> AsyncGenerator[str, None]:
    """
    异步流式聊天（适用于高并发场景）
    
    参数:
        api_url: API 端点
        model: 模型名称
        prompt: 用户提示词
    
    生成:
        异步逐个返回 token
    """
    payload = {
        "model": model,
        "prompt": prompt,
        "stream": True,
    }
    
    async with aiohttp.ClientSession() as session:
        async with session.post(api_url, json=payload) as response:
            if response.status != 200:
                raise Exception(f"API 错误: {response.status}")
            
            # 逐行读取流式响应
            async for line in response.content.iter_lines():
                if line:
                    try:
                        import json
                        data = json.loads(line.decode('utf-8'))
                        token = data.get('response', '')
                        if token:
                            yield token
                    except json.JSONDecodeError:
                        continue


# 使用示例
async def main():
    api_url = "http://localhost:11434/api/generate"
    async for token in stream_chat_async(api_url, "llama3", "写一首诗"):
        print(token, end="", flush=True)

if __name__ == "__main__":
    asyncio.run(main())
```

## 常见问题

### Q1: 如何处理不支持流式的提供商？

**A**: 如果提供商 API 不支持流式，可以：
1. 使用非流式请求获取完整响应
2. 将响应拆分为字符或单词，模拟流式效果
3. 在前端显示加载状态

```python
# 非流式转流式示例
response = client.generate(model=model, prompt=prompt, stream=False)
full_text = response['response']

# 逐字符模拟流式
for char in full_text:
    yield char
    time.sleep(0.01)  # 适当延迟以模拟真实流式
```

### Q2: 如何处理 API 密钥？

**A**: 
- 对于需要 API 密钥的提供商，设置 `requiresAPIKey: true`
- 在 `storage.py` 中从环境变量读取：`os.environ.get(f'{PROVIDER_NAME}_API_KEY')`
- 在 `.env.example` 中添加示例：`PROVIDER_NAME_API_KEY=your_api_key_here`

### Q3: 如何测试新添加的提供商？

**A**:
1. **单元测试**：编写测试用例验证参数映射和错误处理

### Q4: 如何处理不同的响应格式？

**A**: 不同提供商的响应格式可能不同，需要根据文档解析：

```python
# Ollama 格式
token = chunk.get('response', '')

# OpenAI 格式
token = chunk['choices'][0]['delta'].get('content', '')

# Anthropic 格式
token = chunk['completion']
```
